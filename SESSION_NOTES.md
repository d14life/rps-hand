Built 2026-09-10 for the user and their brother: `C:\Users\tagir\Downloads\rps_hand\`.

- `rps_hand.py` (single file): MediaPipe **GestureRecognizer** (VIDEO mode, `assets/gesture_recognizer.task`) gives 21 world landmarks + canned gestures. Closed_Fist/Open_Palm/Victory map to ROCK/PAPER/SCISSORS, with an extended-finger-count fallback. Right half of the pygame+PyOpenGL window renders a 3D hand as GLU capsules driven by the landmarks, **retargeted to canonical bone lengths** (every hand renders the same size, only motion is copied). SPACE plays a round vs the computer.
- Python 3.13, mediapipe 1.0.1 (Tasks API still `mediapipe.tasks.python.vision`), opencv 5, pygame 2.6.
- `test_rps_hand.py [exe]` = self-check: unit asserts + headless run with `--source assets/victory.jpg --shot x.png` (writes `x.png.txt` sidecar because a `--windowed` exe has no stdout). Must print `OK gesture=Victory move=SCISSORS`.
